P01 深度学习核心三件套：前向传播、损失函数、反向传播 ▶

学习目标

理解神经网络最基础的工作方式——数据怎么流过网络（前向），怎么衡量好坏（损失），怎么更新参数（反向传播 + 梯度下降）。

🔥 核心概念

前向传播（Forward Pass）：输入 x → 逐层计算 → 输出预测 ŷ。每一层做的事本质上就是 output = activation(W · input + b)。

损失函数（Loss）：衡量预测 ŷ 和真实标签 y 的差距。分类用交叉熵 CrossEntropyLoss，回归用均方误差 MSELoss。

反向传播（Backpropagation）：用链式法则从损失往回算每个参数的梯度 ∂L/∂W，然后用梯度下降更新参数。

📐 推导 链式法则与梯度下降（手推一遍加深理解）
假设一个两层网络：
  z₁ = W₁ · x + b₁       (线性变换)
  h  = ReLU(z₁)           (激活函数)
  z₂ = W₂ · h + b₂
  ŷ  = softmax(z₂)        (输出概率)
  L  = -∑ yᵢ log(ŷᵢ)     (交叉熵损失)

反向传播（链式法则，从后往前推）：
  ∂L/∂z₂ = ŷ - y                          (softmax + CE 的简洁梯度)
  ∂L/∂W₂ = (∂L/∂z₂) · hᵀ                  (对 W₂ 的梯度)
  ∂L/∂h  = W₂ᵀ · (∂L/∂z₂)                 (传回上一层)
  ∂L/∂z₁ = (∂L/∂h) ⊙ ReLU'(z₁)            (⊙ 逐元素乘)
  ∂L/∂W₁ = (∂L/∂z₁) · xᵀ

参数更新（梯度下降）：
  W ← W - lr × ∂L/∂W     (lr 是学习率)

常用优化器：
  SGD:  最基础
  Adam: 自适应学习率，目前最常用
  AdamW: Adam + 权重衰减（大模型标配）

P02 卷积神经网络（CNN）：从 LeNet 到 ResNet ▶

学习目标

理解 CNN 的基本操作（卷积、池化、特征图），以及 ResNet 的残差连接——这个思想在 Transformer 中同样核心。

🔥 CNN 三个关键概念

卷积核（Kernel/Filter）：一个小的可学习矩阵（如 3×3），在输入图像上滑动做局部特征提取。参数共享 + 局部连接 = 大幅减少参数量。

特征图（Feature Map）：一个卷积核滑过整张图后生成一张特征图。多个卷积核 = 多个特征图 = 多通道输出。

残差连接（ResNet）：output = F(x) + x。让网络学习残差而非完整映射，解决深层网络训练困难的问题。这个思想在 Transformer 的每一层都在用！

📐 推导 卷积操作的数学定义与输出尺寸计算
2D 卷积操作（单通道简化版）：
  输入 X ∈ ℝ^{H×W}，卷积核 K ∈ ℝ^{k×k}
  输出 Y[i,j] = ∑_m ∑_n X[i+m, j+n] · K[m, n]

输出尺寸公式（面试常考）：
  H_out = (H_in - k + 2·padding) / stride + 1
  
例：输入 224×224，卷积核 3×3，padding=1，stride=1
  → H_out = (224 - 3 + 2) / 1 + 1 = 224   （尺寸不变）

例：输入 224×224，卷积核 7×7，padding=3，stride=2
  → H_out = (224 - 7 + 6) / 2 + 1 = 112   （尺寸减半）

多通道卷积：
  输入 C_in 个通道，每个卷积核大小 = C_in × k × k
  N 个卷积核 → 输出 N 个通道
  参数量 = N × C_in × k × k + N（bias）

P03 注意力机制：Scaled Dot-Product Attention 与 Multi-Head ▶

学习目标

注意力机制是 Transformer 的灵魂。彻底理解 Q/K/V 的含义、注意力分数的计算、以及为什么要多头。

📐 推导 注意力机制完整推导（最重要的推导之一）
═══ 核心直觉 ═══
注意力回答的问题：序列中的每个位置应该「关注」其他哪些位置？

类比：你在图书馆找书
  Query (Q)：你要找的主题（「我想找关于猫的书」）
  Key (K)  ：每本书封面上的标签（「动物」「烹饪」「历史」）
  Value (V)：书的实际内容

  注意力 = 用 Q 和每个 K 比对相关度 → 加权提取 V 的内容

═══ Scaled Dot-Product Attention ═══
输入：Q ∈ ℝ^{n×d_k}, K ∈ ℝ^{m×d_k}, V ∈ ℝ^{m×d_v}

Step 1: 计算相似度分数
  S = Q · Kᵀ ∈ ℝ^{n×m}     每对 (query, key) 的点积

Step 2: 缩放（为什么？）
  S = S / √d_k
  原因：d_k 很大时，点积的方差 ≈ d_k，
  导致 softmax 输出接近 one-hot，梯度消失。
  除以 √d_k 让方差回到 1。

Step 3: Softmax 归一化
  A = softmax(S)    每行和为 1，即每个 query 的注意力权重

Step 4: 加权求和
  Output = A · V ∈ ℝ^{n×d_v}

合在一起：
  Attention(Q,K,V) = softmax(QKᵀ / √d_k) · V

═══ Multi-Head Attention ═══
为什么要多头？单个注意力只能学一种「关注模式」。
多头让模型同时关注不同方面（语法、语义、位置...）

  head_i = Attention(QWᵢᴾ, KWᵢᴷ, VWᵢⱽ)
  MultiHead = Concat(head₁, ..., head_h) · Wᴼ

h 个头，每个头的维度 d_k = d_model / h
例：d_model=768, h=12 → 每个头 64 维
🔥 Self-Attention vs Cross-Attention

Self-Attention：Q、K、V 都来自同一个序列。每个 token 看序列中所有其他 token。ViT 和 GPT 的核心。

Cross-Attention：Q 来自一个序列，K/V 来自另一个序列。用于不同模态之间的交互（后面多模态会用到）。

P04 Vision Transformer（ViT）：把图像变成序列 ▶

学习目标

ViT 的核心思想极其简单——把图像切成小块（patch），当作「单词」，然后用标准 Transformer 处理。这个思想直接奠定了后面所有多模态模型的基础。

📐 推导 ViT 完整流程（从图像到分类结果）
═══ Step 1: Patch Embedding ═══
输入图像 x ∈ ℝ^{H×W×C}，如 224×224×3

切成 N 个 patch，每个 patch 大小 P×P
  N = (H/P) × (W/P) = (224/16) × (224/16) = 196 个 patch

每个 patch 展平为向量：P×P×C = 16×16×3 = 768 维
再通过线性投影映射到 d_model 维：
  patch_embed = Linear(P²·C, d_model)

═══ Step 2: 添加特殊 token 和位置编码 ═══
在序列最前面加一个 [CLS] token（可学习）：
  序列变为 [CLS, patch₁, patch₂, ..., patch₁₉₆]
  长度 = 197

加上可学习的位置编码（每个位置一个 d 维向量）：
  z₀ = [x_cls; patch₁E; ...; patch_N·E] + E_pos
  E_pos ∈ ℝ^{(N+1)×d}

═══ Step 3: Transformer Encoder ═══
标准的 L 层 Transformer Encoder（和 BERT 一样）：
  每层：LayerNorm → Multi-Head Self-Attention → 残差
       → LayerNorm → FFN (MLP) → 残差

注意：这里是双向注意力（不是 GPT 的因果注意力）
每个 patch 可以看到所有其他 patch

═══ Step 4: 分类头 ═══
取 [CLS] token 的最终表示 → MLP Head → 类别概率
  y = MLP(LayerNorm(z_L[0]))

参数量估算（ViT-Base）：
  d=768, L=12 层, h=12 头
  ≈ 86M 参数（和 ResNet-50 的 25M 相比更大）
🔥 ViT 的关键洞察

CNN vs ViT 的本质差异：CNN 通过卷积核天然具有局部感受野和平移不变性；ViT 没有这些归纳偏置（inductive bias），完全靠数据学习。所以 ViT 在小数据集上不如 CNN，但在大数据集上远超 CNN。

为什么 ViT 对多模态如此重要：ViT 让图像和文本统一成了相同的表示形式——token 序列。这为后面把图像 token 和文本 token 拼在一起送入 LLM 铺平了道路。

D01 Encoder vs Decoder：从 ViT 到 GPT 的思维转变 ▶

学习目标

理解 Encoder-only（BERT / ViT）、Decoder-only（GPT）、Encoder-Decoder（T5）三种架构的本质差异，搞清楚为什么现在主流 LLM 都选择 decoder-only。

🔥 核心概念

Causal Attention（因果注意力）是 decoder-only 和你熟悉的 ViT 最根本的区别。ViT 中每个 patch token 可以看到所有其他 token（双向注意力），GPT 中每个 token 只能看到它之前的 token（单向），通过 causal mask 实现。

理解这一点就理解了「自回归生成」——模型一个 token 一个 token 地预测下一个词。

📐 推导 Causal Attention 与标准 Self-Attention 的区别
标准 Self-Attention（你在 ViT 里熟悉的）：
  Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V

Causal Self-Attention（GPT 使用的）：
  Attention(Q, K, V) = softmax(QKᵀ / √d_k + M) · V
  其中 M 是上三角 mask 矩阵，M_ij = 0 if i≥j, else -∞

效果：位置 i 的 token 只能 attend 到 [0, 1, ..., i]，
看不到未来的 [i+1, i+2, ...] 位置。

D02 Tokenization：BPE、SentencePiece 与词表设计 ▶

学习目标

理解文本如何变成 token ID 序列。这是 CV 人最容易忽略的部分——图像天然是连续的，但语言模型的输入是离散的整数序列。

🔥 核心概念

BPE（Byte Pair Encoding）是目前主流的 tokenizer 算法。核心思路：从字符级开始，不断合并出现频率最高的 pair，直到词表达到预设大小。

词表大小直接影响：嵌入层参数量、序列长度（词表越大同一段文本 token 越少）、多语言能力。

📐 推导 BPE 算法完整步骤（需要手动走一遍）
初始词表：所有单个字符 {'l','o','w','e','r','n','s','t','i','d',...}
语料频率统计：l o w = 5次, l o w e r = 2次, n e w e s t = 6次 ...

迭代过程：
  Step 1: 统计所有相邻 pair 的频率
    ('e','s') 出现 9 次 → 最高 → 合并为 'es'
  Step 2: 更新语料，重新统计
    ('es','t') 出现 9 次 → 合并为 'est'
  Step 3: 继续...
  直到词表大小 = 目标值（如 32000）

现代变体：
  - Byte-level BPE（GPT-2/3/4）：以 byte 而非 unicode 字符为起点
  - SentencePiece（Llama/Qwen）：直接在原始文本上训练，不需要预分词

D03 GPT 完整架构：从 Embedding 到输出概率 ▶

学习目标

完整理解 GPT 系列的前向传播过程：token embedding + positional encoding → N 层 decoder block → lm_head → 概率分布。

🔥 GPT Decoder Block

结构（每层重复 N 次）：x → LayerNorm → Causal Multi-Head Self-Attention → 残差连接 → LayerNorm → FFN（MLP）→ 残差连接 → output

和 ViT Block 的区别：(1) attention 有 causal mask；(2) 没有 cross-attention（纯 decoder）；(3) 通常用 Pre-Norm（ViT 也是）。

📐 推导 完整前向过程与参数量估算（面试常考）
完整前向过程（对照 nanoGPT 代码理解）：

1. Token Embedding: E ∈ ℝ^{V × d}，将 token ID 映射为向量
   h₀ = E[x] + PE    (PE: 位置编码)

2. Transformer Layers (×N):
   h'ₗ = hₗ + CausalMHA(LayerNorm(hₗ))
   hₗ₊₁ = h'ₗ + FFN(LayerNorm(h'ₗ))

   其中 FFN(x) = W₂ · GELU(W₁ · x)
   （现代模型如 Llama 用 SwiGLU: FFN(x) = W₂ · (SiLU(W₁x) ⊙ W₃x)）

3. 输出层:
   logits = LayerNorm(h_N) · Eᵀ   (权重共享)
   P(next_token) = softmax(logits)

参数量估算（重要！面试常考）：
  Embedding: V × d
  每层 Attention: 4 × d²（Q/K/V/O 四个投影矩阵）
  每层 FFN: 约 8d²（标准）或 ~8d²（SwiGLU）
  总参数 ≈ 12 × N × d²（N 是层数，d 是隐藏维度）
  7B 模型：N=32, d=4096 → 12 × 32 × 4096² ≈ 6.4B ✓

D04 位置编码：从 Sinusoidal 到 RoPE ▶

学习目标

Transformer 本身对位置不敏感（permutation invariant），必须注入位置信息。理解三代位置编码的演进。

📐 推导 三代位置编码对比（RoPE 重点理解）
═══ 第一代：Sinusoidal（原始 Transformer / ViT）═══
  PE(pos, 2i) = sin(pos / 10000^{2i/d})
  PE(pos, 2i+1) = cos(pos / 10000^{2i/d})
  加到 embedding 上：h₀ = E[x] + PE
  问题：绝对位置，无法外推到训练长度之外

═══ 第二代：ALiBi（BLOOM）═══
  不加到 embedding，而是加到 attention score 上：
  Attention_ij += -m × |i - j|
  m 是每个 head 不同的斜率
  简单但有效，天然支持外推

═══ 第三代：RoPE（Llama/Qwen/大多数现代模型）═══
  核心思想：用旋转矩阵编码相对位置
  对 q, k 向量在每对维度上做旋转：
  [q_{2i}]     [cos(mθᵢ)  -sin(mθᵢ)] [q_{2i}]
  [q_{2i+1}] = [sin(mθᵢ)   cos(mθᵢ)] [q_{2i+1}]
  其中 m 是位置，θᵢ = 10000^{-2i/d}

  qᵐ · kⁿ 的内积只依赖于 m-n（相对距离）！
  这就是「旋转位置编码」名字的由来。
🔥 为什么 RoPE 成为标准

它优雅地实现了：(1) 注意力分数只依赖相对位置；(2) 通过 NTK-aware scaling 可以外推到更长序列；(3) 计算开销极小。你后面看的所有模型（Llama、Qwen、InternVL）都用 RoPE。

D05 语言模型训练：Next Token Prediction 与采样策略 ▶

学习目标

理解预训练目标（next token prediction）的损失函数，以及推理时如何从概率分布采样生成文本。

📐 推导 预训练损失与 Perplexity
预训练损失函数：

给定序列 x = (x₁, x₂, ..., xₜ)
L = -∑ᵢ log P(xᵢ | x₁, ..., xᵢ₋₁; θ)

即标准的交叉熵损失。和你做分类任务的 CE loss 一模一样，
只不过这里「分类」的类别数 = 词表大小 V（通常 32K-150K）。

Perplexity（困惑度，评估指标）：
PPL = exp(L / T)    T 是序列长度
PPL 越低越好，直觉上代表「平均每个位置模型犹豫的选项数」。
🔥 采样策略（面试高频）

Greedy：每步选概率最大的 token。确定性但无聊。
Temperature：logits / T 后再 softmax。T<1 更确定，T>1 更随机。
Top-k：只保留概率最高的 k 个 token，其余置 0 后重新归一化。
Top-p（Nucleus）：保留累积概率达到 p 的最小 token 集合。自适应，比 top-k 更灵活。
Repetition Penalty：降低已出现 token 的概率，减少重复。

D07DPO：不需要 Reward Model 的对齐方法▶

学习目标

RLHF 太复杂（需要训练 reward model + PPO），DPO 把它简化成了一个简单的分类问题。现在大多数开源模型都用 DPO 或其变体。

📐 推导 DPO 损失函数完整推导
RLHF 的目标（Bradley-Terry 模型）：
  P(y_w ≻ y_l | x) = σ(r(x, y_w) - r(x, y_l))
  其中 y_w 是人类偏好的回答，y_l 是被拒绝的

RLHF 需要先训练 reward model r(x,y)，再用 PPO 优化策略。

DPO 的关键洞察：
  最优策略 π* 和 reward 之间有解析关系：
  r(x,y) = β log(π*(y|x) / π_ref(y|x)) + const

  代入 Bradley-Terry 模型，reward model 被消掉了！

  得到 DPO loss：
  L_DPO = -E[log σ(β log(π_θ(y_w|x)/π_ref(y_w|x))
                   - β log(π_θ(y_l|x)/π_ref(y_l|x)))]

  直觉：让模型增加好回答的概率、降低差回答的概率，
  同时不偏离参考模型太远（通过 β 控制）。

D08LoRA：低秩适配的原理与实现▶

学习目标

LoRA 是你后面做任何微调实验的基础工具，必须吃透。

📐 推导 LoRA 核心数学（务必理解）
全量微调：W' = W + ΔW    ΔW ∈ ℝ^{d×d}（参数量巨大）

LoRA 的假设：ΔW 是低秩的，可以分解为：
  ΔW = B · A    其中 A ∈ ℝ^{r×d}, B ∈ ℝ^{d×r}
  r ≪ d（rank，通常 8-64）

前向传播：h = (W + ΔW)x = Wx + BAx

参数量对比（以 d=4096, r=16 为例）：
  全量微调 ΔW：4096 × 4096 = 16.7M 参数/层
  LoRA (A+B)：4096×16 + 16×4096 = 131K 参数/层
  压缩比：128x！

初始化：
  A ~ N(0, σ²)   （随机初始化）
  B = 0           （零初始化，保证训练开始时 ΔW=0）
  缩放因子：α / r（α 通常设为 r 的 1-2 倍）
🔥 QLoRA

QLoRA = 量化基础模型 + LoRA。基础模型以 4-bit NF4 格式加载（省内存），只训练 LoRA 的 A/B 矩阵（FP16/BF16）。这就是你在 32GB MacBook 上能微调 7B 模型的原因。

D10MoE 架构与 KV Cache 推理优化▶

学习目标

理解两个在现代 LLM 中无处不在的工程概念：Mixture of Experts（稀疏激活）和 KV Cache（加速推理）。

📐 推导 MoE 与 KV Cache 原理
═══ Mixture of Experts (MoE) ═══
标准 FFN：y = FFN(x)（每个 token 都经过同一个 FFN）
MoE FFN：
  gate(x) = softmax(W_g · x)  → 路由概率（K 个专家）
  选择 top-k 个专家（通常 k=2）
  y = ∑ᵢ gate_i(x) · FFNᵢ(x)（只计算被选中的专家）
例：Mixtral 8×7B → 8 个专家，每次激活 2 个
  总参数 46.7B，但每个 token 只用 ~13B → 推理快，效果好

═══ KV Cache ═══
自回归生成时，第 t 步需要：
  Attention(q_t, [k₁,...,k_t], [v₁,...,v_t])
观察：k₁...k_{t-1} 和 v₁...v_{t-1} 之前已经算过了！
KV Cache：缓存所有已计算的 K 和 V，每步只需要：
  1. 计算新 token 的 q_t, k_t, v_t
  2. 把 k_t, v_t 追加到缓存
  3. q_t attend 到整个缓存
内存占用：2 × n_layers × d_model × seq_len × dtype_size
  7B 模型 4096 context: ≈ 1GB

D11CLIP：对比学习对齐视觉与语言▶

学习目标

CLIP 是几乎所有多模态大模型的视觉编码器来源。理解它的训练方式和特征空间性质。

📐 推导 CLIP 对比学习损失（InfoNCE）
训练数据：N 对 (image, text) pairs
图像编码器：f_img(x) → 归一化向量 v ∈ ℝ^d
文本编码器：f_txt(t) → 归一化向量 u ∈ ℝ^d

相似度矩阵：S_ij = τ · (vᵢ · uⱼ)    τ 是可学习的温度参数

Image-to-Text loss:
  L_i2t = -∑ᵢ log(exp(S_ii) / ∑ⱼ exp(S_ij))
Text-to-Image loss:
  L_t2i = -∑ⱼ log(exp(S_jj) / ∑ᵢ exp(S_ij))
总 loss = (L_i2t + L_t2i) / 2

直觉：对角线元素（匹配对）的相似度要大于所有非对角线（不匹配）。
batch 越大，负样本越多，学到的特征空间越好。
CLIP 原论文用了 32768 的 batch size！
🔥 为什么 CLIP 如此重要

CLIP 的视觉编码器（通常是 ViT-L/14 或 ViT-bigG）把图像编码成一组 token 序列，这些 token 天然就和文本语义对齐了。后面的 LLaVA 等模型只需要一个小的 projector 就能把这些视觉 token「翻译」成 LLM 能理解的格式。

D12SigLIP 与视觉编码器的选择▶

学习目标

CLIP 的 softmax 对比需要超大 batch，SigLIP 用 sigmoid 替代解决了这个问题。了解不同视觉编码器在多模态模型中的使用。

📐 推导 SigLIP 的改进（对比 CLIP）
SigLIP：每个 pair 独立做 sigmoid binary classification
L = -∑ᵢ∑ⱼ [ y_ij·log σ(S_ij) + (1-y_ij)·log(1-σ(S_ij)) ]
其中 y_ij = 1 if i=j（匹配对），else 0

优势：
  1. 不需要跨 GPU 同步负样本（训练更高效）
  2. 可以用更大的 batch size
  3. 实际效果和 CLIP 持平甚至更好
🔥 主流 MLLM 的视觉编码器

LLaVA-1.5: CLIP ViT-L/14 (336px) · InternVL2: InternViT-6B（自训练的超大 ViT）· Qwen-VL: ViT-bigG（OpenCLIP）· Gemma 4 / PaliGemma: SigLIP ViT-So400m。趋势：越来越多模型用 SigLIP 替代 CLIP。

D13视觉 Token：从图像到 LLM 输入序列▶

多模态模型的核心问题：如何把图像变成 LLM 能处理的 token？理解 visual tokenization 的不同方案。

🔥 图像 → 视觉 token 的流程

① 图像经过 ViT：224×224 图像 → (224/14)² = 256 个 patch token
② 高分辨率处理：336px → 576 tokens，448px → 1024 tokens
③ Connector/Projector 将视觉 token 映射到 LLM 的 embedding 空间

D17Qwen-VL 系列：中文多模态的标杆▶

学习目标

Qwen-VL 在中文多模态领域几乎是标杆。理解它的架构特点和训练数据策略。

📐 推导 M-RoPE（Multimodal RoPE，Qwen2-VL 的创新）
标准 RoPE：每个 token 有 1D 位置 m
M-RoPE：每个 token 有 3D 位置 (t, h, w)
  t = 时间维度（视频帧号）
  h, w = 空间维度（patch 的行列位置）

将 d 维 head 分成三段：
  dim[0:d/3]    → 用 t 做 RoPE（时间位置）
  dim[d/3:2d/3] → 用 h 做 RoPE（垂直位置）
  dim[2d/3:d]   → 用 w 做 RoPE（水平位置）

对于文本 token：t=h=w=当前序列位置（退化为标准 RoPE）
对于图像 token：t=固定，h/w=patch 在图像中的行列坐标

这样模型天然知道「这个 patch 在图像的左上角还是右下角」。

D24视频理解：从图像到时序多模态▶

学习目标

视频 = 图像序列 + 时间维度。理解 MLLM 如何处理视频输入。

🔥 主流视频处理方案

① 均匀帧采样：从视频中等间隔抽 N 帧（如 8 帧），每帧独立编码后拼接。最简单也最常用。
② 时序 token 压缩：相邻帧的相似 token 合并，减少冗余。
③ SlowFast 思路：少数帧提取细节，多数帧提取动态。
核心矛盾：视频帧数 × 每帧 token 数 = 总 token 数爆炸。

D25多模态幻觉与对齐问题▶

学习目标

多模态幻觉（hallucination）是当前最大的问题之一：模型「看到」图中不存在的东西。

D26LLM Agent 框架：ReAct、Tool Use、Planning▶

学习目标

Agent 的核心：感知 → 推理 → 行动 → 观察 的循环。理解 ReAct 范式。

🔥 ReAct 范式

LLM 交替生成「思考」和「动作」：Thought → Action → Observation → Thought → ... 这比固定 CV pipeline 灵活得多——不是固定流程，而是根据中间结果动态决策。

🔥 Function Calling / Tool Use

模型输出结构化的函数调用（JSON 格式），外部系统执行后把结果返回给模型。例：模型输出 {"name": "enhance_image", "args": {"path": "dark.jpg"}}，系统执行图像增强，返回增强后的图像。

📐 推导 RAG 基本流程
1. 离线索引阶段：
   文档 → 分块 → Embedding Model → 向量数据库

2. 在线检索阶段：
   用户 Query → Embedding → 向量检索 Top-K 相关文档

  sim(q, d) = (q · d) / (||q|| × ||d||)

  不只检索文本，还检索图像/图表/表格

D34多模态模型的训练效率优化▶

学习目标

了解如何用有限算力高效训练多模态模型。

🔥 关键技术

DeepSpeed / FSDP：分布式训练框架 · 混合精度训练：BF16 + FP32 master weights · 梯度检查点：用计算换内存 · Flash Attention 2/3：IO-aware attention 实现

📐 推导 Flash Attention 核心思想
标准 Attention 的内存瓶颈：
  S = QKᵀ ∈ ℝ^{N×N}     ← N=4096 就要 64MB
  P = softmax(S)
  O = PV

Flash Attention：
  不存储完整的 S 和 P 矩阵
  把 Q, K, V 分成 blocks，在 SRAM（高速缓存）中计算
  利用 online softmax 技巧避免需要全局 max

结果：内存从 O(N²) 降到 O(N)，速度提升 2-4x
